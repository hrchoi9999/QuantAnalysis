- I-STOCK-STRONG-RSI-V01(가격 강도/재가속 확인 모델): 최근 시장이 약해도 버티거나 다시 강해지는 종목을 찾는다. RSI, 가격 강도, 재가속 흐름을 중심으로 본다.
- S2(펀더멘털 기반 안정형 주식 모델): 품질, 성장, 재무 개선, 시장 게이트를 함께 보며 대형 우량주와 실적 기반 종목이 많이 남는다.
