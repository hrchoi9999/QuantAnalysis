# QuantService 추가 작업요청서: 투자 포트폴리오 단계별 상세 설명 보강

## 요청 배경
현재 redbot.co.kr `투자 포트폴리오` 페이지는 단계별 판단 제목은 표시되지만, 각 단계에서 왜 그런 결론이 나왔는지 설명하는 상세 내역이 부족하다.

## 유지할 내용
- 기존 `단계별 판단` 요약 리스트는 그대로 유지한다.
- 요약 리스트에는 단계명과 결과만 간단히 표시한다.

## 추가할 내용
요약 리스트 아래에 `단계별 상세 설명` 섹션을 추가한다.

각 단계는 아래 구조로 표시한다.
- 단계 번호와 제목
- 한 문장 요약
- 상세 근거 목록
- 단계별 결론

## 데이터 원천
우선 DB를 사용한다.

- DB: `D:\QuantAnalysis\analysis.db`
- 최신 실행 조회 기준: `portfolio_runs.run_id = max(run_id)`
- 상세 설명 테이블: `portfolio_step_details`
  - `step_no`
  - `title`
  - `summary`
  - `details_json`
  - `conclusion`

Fallback으로 최신 JSON을 사용할 수 있다.

- JSON: `D:\QuantAnalysis\outputs\investment_portfolio_latest.json`
- 필드: `step_details`

## 렌더링 순서
1. 상단 요약
2. 단계별 판단 요약 리스트
3. 단계별 상세 설명
4. 시장 위험
5. ETF 전략
6. 주식 후보
7. 고지 문구

## 표시 예시
- `1. 시장 위험 판단`
  - 요약: 시장 전체가 상승 종목보다 하락 종목이 훨씬 많고, 외국인과 프로그램 매도 압력이 강해 방어적 판단을 우선했다.
  - 근거: 시장판단, 시장 점수, KOSPI/KOSDAQ 상승비율, 외국인/기관/프로그램 수급
  - 결론: 공격적 주식 매수보다 방어형 자산과 현금성 자산을 우선한다.

## 완료 기준
- 기존 단계별 판단 요약 리스트가 유지된다.
- 그 아래에 1~6단계 상세 설명이 모두 표시된다.
- 사용자가 최종 포트폴리오 결론까지의 판단 흐름을 페이지 안에서 이해할 수 있다.
- 모바일에서도 상세 근거 목록이 깨지지 않는다.
